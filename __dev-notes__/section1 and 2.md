# Notes

## Overview

The stack:

- nextjs 15 / react 19
- postgresql
- prisma orm
- typescript, ESline and Zod
- shadCN Ui
- next auth
- react hook form
- jest testing for paypal payments (also does stripe payments)
- vercel deployment from github

Stripe provides a dummy credit card to pay as well; and you can login as an admin and as a user. The admin has a recent sales dashboard as well as other features; managing products, managing orders, user profiles, and see all their details.

Prisma studio shows you how to use all the items in your database as well. Has a scroller for adds at the top.

This is live on vercel to preview.
